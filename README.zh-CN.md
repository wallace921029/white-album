# White Album (家庭相册)

**White Album** 是一个全栈 Web 应用程序，专为打造私密、安全的家庭相册和通知中心而设计。它为家庭成员提供了一个专属空间，用于分享回忆并随时了解家庭事务，特别针对平板设备（如 iPad）和手机的浏览体验进行了优化。

## 项目架构

本项目在同一个代码仓库中包含两个独立的 npm 项目：

- **前端** (`/`)：使用 React 19、Vite 8 和 TypeScript 构建的现代化 UI。使用 Tailwind CSS v4 和 `shadcn/ui` 进行样式设计。
- **后端** (`/backend`)：由 Fastify 5 和 TypeScript 驱动的强大 REST API。采用 Drizzle ORM 和 `better-sqlite3` 实现高效、轻量的无服务器数据持久化，负责处理应用数据和上传的图片文件。

## 主要功能

- **基于角色的访问及邀请码系统**：确保隐私安全。首位注册的用户将自动成为管理员，管理员可生成一次性邀请码供其他家庭成员注册加入。
- **照片管理**：管理员可以上传照片、添加文字说明并调整照片的轮播顺序，普通成员则可以安全地浏览共享的家庭相册。
- **通知中心与留言板**：管理员可发布置顶的重要家庭通知；应用还提供留言板，供成员发表留言和互动。
- **管理员仪表盘**：为管理员提供全面的后台管理界面，以便轻松管理照片、通知和邀请码。

## 快速开始

### 环境要求
- Node.js (推荐 v18+)
- npm

### 安装依赖

1. 安装前端依赖：
   ```bash
   npm install
   ```
2. 安装后端依赖：
   ```bash
   cd backend
   npm install
   ```

### 本地开发

你可以从项目根目录使用提供的脚本同时启动前端和后端的开发服务器：

- **Windows (PowerShell)**：`./dev.ps1`
- **Mac/Linux (bash)**：`./dev.sh`

或者，你也可以分别运行它们：
- **前端**：`npm run dev` (运行在 5173 端口)
- **后端**：`cd backend && npm run dev` (运行在 3000 端口)

### 生产环境构建

- **前端**：`npm run build`
- **后端**：`cd backend && npm run build`，然后执行 `npm start` 启动生产服务器。

*注：后端服务器在启动时会自动应用数据库迁移 (Migrations)。*
